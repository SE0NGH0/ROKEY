# 🗺️ SLAM 기반 장애물 인식 및 자율 탐색 시스템  

---

## 📌 Project Overview

본 프로젝트는 **TurtleBot4 + ROS2** 환경에서  
**SLAM 기반 자율 주행**과 **프론티어 탐색 알고리즘**,  
**비주얼 트래킹 및 맵 저장 자동화 기능**을 구현한 것입니다.

---

## 🎯 핵심 기능

| 기능 | 설명 |
|------|------|
| **SLAM Mapping** | ROS2 `/map` 토픽 구독 및 실시간 맵 처리 |
| **Frontier Detection** | 자유공간과 미탐색 공간의 경계 기반 프론티어 탐지 |
| **Goal Generation** | DBSCAN 클러스터링을 활용한 최적 목표 지점 설정 |
| **Navigation** | 목표 전송 후 이동 결과 확인 및 자동 정지 처리 |
| **Map Save & Stop** | 탐색 종료 판단 시 맵 저장 및 로봇 정지 |
| **Visual Tracking** | ORB + Optical Flow 기반 객체 추적 |

---

## 📐 맵 처리 로직

- `/map` 토픽 구독 → 2D 배열 변환
- 프론티어 탐색 비율 임계값 기준으로 탐색 종료 판단
- 탐색 완료 시 맵 파일로 저장 및 정지 명령 (`/cmd_vel = 0`)
- 목표가 유효하면 Navigation 서버로 전송 및 결과 모니터링

---

## 📌 목표 지점 계산 로직

1. 자유공간 (0) & 미탐색 공간 (-1) 경계에서 프론티어 검출
2. **DBSCAN 알고리즘**으로 클러스터링
3. 중심점 계산 → 로봇과 가장 가까운 목표로 설정
4. 10초 간격으로 목표 업데이트

---

## 🧭 비주얼 트래커 로직

- `cv.ORB_create()`로 ORB 특징점 생성
- 첫 프레임에서 특징점 검출 후 Optical Flow로 추적
- 매 N프레임마다 ORB 재실행하여 새로운 특징점 추가
- 기존 + 신규 특징점 병합 → 추적 안정성 강화

## 🛠 ROS2 파라미터 튜닝 요약

### `nav2.yaml`
| 파라미터 | 변경 전 → 변경 후 | 설명 |
|----------|-------------------|------|
| PathAlign.scale | 32.0 → 40.0 | 경로 정렬 강화 |
| GoalAlign.scale | 24.0 → 30.0 | 목표 정렬 강화 |
| Max_vel_theta | 1.0 → 0.3 | 회전 속도 감소 |
| Robot_radius | 0.175 → 0.17 | 충돌 최소화 |
| Inflation_radius | 0.45 → 0.2 | 회피 범위 조정 |

### `slam.yaml`
| 파라미터 | 변경 전 → 변경 후 | 설명 |
|----------|-------------------|------|
| Map_update_interval | 0.5 → 5.0 | 계산 부하 감소 |
| Resolution | 0.05 → 0.02 | 고해상도 맵 |
| Do_loop_closing | true → false | 루프 클로저 비활성화 |
