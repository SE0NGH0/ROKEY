# Project8

# 🏗️ ROS2 기반 협동로봇 컵 탑쌓기 자동화 실습  

---

## 📌 Project Overview

본 프로젝트는 **두산로보틱스 M0609 모델**과 **ROS2 서비스 통신**을 활용하여,  
컵을 자동으로 집어서 여러 층으로 탑처럼 쌓는 협동로봇 동작 시나리오를 구현한 실습입니다.

---

## 🎯 프로젝트 목표

- **총 4층의 탑을 쌓는 Pick & Place 알고리즘 구현**
- **11개의 컵을 활용하여 1~4층으로 배치**
  - 1층: 6개 → 삼각형 모양
  - 2층: 3개 → 삼각형 모양
  - 3층: 1개
  - 4층: 1개 (뒤집어서 올림)

---

## 🧠 동작 시나리오

### 1. Place 경로 계산

- 초기 기준 좌표에서 층별로 경로 생성
- 1층은 가로로 정렬된 3개 + 다음 줄 3개
- 위로 갈수록 컵 개수 감소 (지그재그 배치)
- 각 층은 z축을 증가시키며 위치 설정

### 2. Pick 경로 계산

- 쌓여 있는 컵 스택에서 높이(z)만 다른 위치를 추출
- base_height(250)에서 시작 → i번째는 z = base_height - i×11
- X, Y, RPY 값은 고정

### 3. Pick & Place 반복

- 순서대로 Pick → Place 위치로 이동
- Gripper 열고 닫는 함수로 집기 수행
- 힘 제어 및 선형 이동으로 안전한 동작 보장

### 4. 마지막 컵(4층)은 별도 좌표로 직접 이동하여 뒤집어 놓기

---

## 💻 코드 구현 요약

| 항목 | 내용 |
|------|------|
| 좌표 계산 | X +38 / Y +22 / Z +95 방식으로 층 구분 |
| 속도 설정 | 속도 및 가속도 = 170 |
| 경로 저장 | `path[]`, `PlaceList[]` |
| 피킹 위치 | `base_z = 250 - i×11` 계산 |
| 안전 제어 | Z가 높으면 pick_z = 360 으로 설정 |
| 최종 동작 | 전체 경로 순환하며 Pick & Place 수행
