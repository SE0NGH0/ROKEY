# Project6
# 🤝 DART 협동로봇 동작 운영 실습  

---

## 📌 Project Overview

본 프로젝트는 **두산로보틱스의 DART 플랫폼**과 **ROS2**를 활용하여  
협동로봇의 기본 동작, 경로 설정, 시뮬레이션을 실습하고,  
직접적인 모션 제어 및 좌표기반 움직임을 구현한 실습 프로젝트입니다.

---

## 🤖 실습 개요

- **플랫폼**: 두산로보틱스 DART Studio + Simulation
- **제어 인터페이스**: ROS2 기반 Python 스크립트
- **목표**: 협동로봇의 기본 모션, 위치 제어, 경로 설정 학습 및 실습
