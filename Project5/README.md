# Project5

# 🧠 PCD 기판 자동 불량 검출 시스템 (PICO Auto Detection)  

---

## 📌 Project Overview

본 프로젝트는 **YOLOv6 기반 AI 비전 모델**을 활용하여  
**PCB(Printed Circuit Board)** 상의 부품 불량을 자동으로 검출하고 분류하는 시스템입니다.  
컨베이어 라인, 적외선 센서, Raspberry Pi, 카메라, Superb AI 플랫폼 등을 통합하여  
실시간 검사, 시각화, 데이터 저장까지 이루어지는 **AI 기반 품질 검사 자동화 솔루션**을 구현하였습니다.

🎥 [📽 시연 영상 보기](https://youtube.com/shorts/iStBSuXnV2U)

---

## 🔩 시스템 구성

### ✅ 전체 흐름

1. **컨베이어 동작 시작**  
2. **IR 센서**가 PCD 기판 감지 시 컨베이어 정지  
3. 카메라로 이미지 촬영 → YOLO 모델을 통한 불량 판정  
4. **Raspberry Pi**가 결과 수신 → 양품/불량 구분  
5. 결과 데이터는 **데이터베이스**에 저장되어 관리

---

- 적외선 센서
- 카메라
- Raspberry Pi
- PCD 정렬 라인

---

## 🖥️ 소프트웨어 요소

- **YOLOv6-M 모델** 기반 객체 탐지
- 각 부품 개수 및 명칭 시각화 표시
- 양품(Normal) / 불량(Poor) 텍스트 출력
- DB 연동을 통한 재고 관리 및 이력 추적

---

## 🧪 모델 학습 및 개선 과정

- 총 1510장 이미지 수집 및 라벨링
- 이미지 크롭 및 고해상도(1920x1080) 사용
- 클래스 수: 6개, 박스 수: 9개
- **Superb AI 플랫폼** 기반 학습
- 다양한 실험을 통해 mAP 및 탐지 정확도 개선

| 단계 | 데이터 수 | mAP | 9개 박스 전부 탐지 정확도 |
|------|------------|------|---------------------------|
| 초기 | 111장 | 42.3% | 0% |
| 개선 | 755장 | 89.1% | 54.6% |
| 최종 | 1510장 | 90.1% | 39.9% |

---

## 📊 모델 성능 (최종 결과)

- mAP: **90.1%**
- Accuracy: **54.6%**
- Precision: **1.21%**
- Recall: **30%**
- F1 Score: **2.33%**
- 검사 시간: **1.08초 / unit**
- 생산량: **3333 units / hour**
